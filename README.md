# vertice-cache

Módulo de gestión y abstracción de caché para el ecosistema Vértice.

## Changelog

### [0.1.0] - Caché Local

- **Creación**:
  - Implementación inicial del sistema de caché local en memoria y estructura base de contenedores.
  - Documentación técnica (Javadoc) en todas las clases y componentes del módulo.
- **Uso**:
  - Permite a los módulos del ecosistema almacenar y recuperar instancias temporales de forma rápida y concurrente en memoria, sin necesidad de configurar dependencias o servicios externos.
